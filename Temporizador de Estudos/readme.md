# ⏱️ Temporizador de Estudos

## 📌 Descrição

Este projeto consiste em um **Temporizador de Estudos**, desenvolvido com o objetivo de auxiliar na organização do tempo dedicado aos estudos. A aplicação permite controlar períodos de estudo e pausa, ajudando a manter o foco e melhorar a produtividade.

O projeto foi desenvolvido como **atividade prática**, com foco no aprendizado de lógica de programação, controle de tempo e uso de recursos da linguagem.

---

## 🎯 Objetivo da Atividade

* Praticar conceitos de programação
* Trabalhar com controle de tempo (temporizador)
* Desenvolver raciocínio lógico
* Simular uma ferramenta útil para o dia a dia de estudos

---

## 🛠️ Tecnologias Utilizadas

* **Java**
* IDE: *Spring Tools Eclipse* (ou outra de sua preferência)
* Execução via **terminal/console**

---

## ⚙️ Funcionalidades

* Iniciar temporizador de estudos
* Contagem regressiva do tempo definido
* Exibição do tempo no console
* Finalização automática ao término do tempo
* **Formatação de datas e horas** para exibição amigável
* Registro do **horário de início e término** da sessão de estudos

---

## ▶️ Como Executar o Projeto

1. Clone ou baixe este repositório
2. Abra o projeto em sua IDE Java
3. Compile o arquivo principal
4. Execute o programa pelo terminal ou pela IDE

```bash
javac Program.java
java Program
```

## 🧠 Aprendizados

Com este projeto, foi possível reforçar conceitos importantes da programação e entender como criar soluções simples que podem ser aplicadas no cotidiano, como a organização do tempo de estudos.

Além disso, o uso da **API de Data e Hora do Java** permitiu compreender como trabalhar com horários reais, formatar datas para melhor visualização e registrar eventos importantes durante a execução do programa.
