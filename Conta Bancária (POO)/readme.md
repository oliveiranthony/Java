# 💰 Sistema Bancário em Java

Projeto desenvolvido em **Java** com foco em **Orientação a Objetos**, simulando operações básicas de uma conta bancária via terminal.

Este projeto foi criado com o objetivo de **praticar conceitos fundamentais da programação orientada a objetos**, lógica de programação e interação com o usuário através do console.

---

## 📌 Funcionalidades

* 📥 **Depósito** de valores na conta
* 📤 **Saque** com atualização automática do saldo
* 📄 **Exibição dos dados da conta**
* 🧠 Atualização dinâmica do saldo conforme as operações
* ⌨️ Menu interativo via terminal

---

## 🧱 Estrutura do Projeto

O projeto é dividido em duas classes principais:

### 🔹 `ContaBancaria`

Responsável por representar a conta e conter as regras de negócio:

* Atributos privados (encapsulamento)
* Métodos para depósito e saque
* Método para exibir os dados atualizados da conta

### 🔹 `Program`

* Classe principal (`main`)
* Responsável pela interação com o usuário
* Controle do menu e chamadas dos métodos da conta

---

## 🧠 Conceitos Aplicados

* ✔️ Orientação a Objetos (OOP)
* ✔️ Encapsulamento
* ✔️ Métodos não estáticos
* ✔️ Uso de `Scanner` para entrada de dados

## ▶️ Como Executar o Projeto

1. Clone o repositório:

```bash
git clone https://github.com/seu-usuario/seu-repositorio.git
```

2. Acesse a pasta do projeto

3. Compile os arquivos:

```bash
javac Program.java ContaBancaria.java
```

4. Execute o programa:

```bash
java Program
```
