# 💼 Sistema de Gerenciamento de Funcionários

Este projeto foi desenvolvido como **atividade de estudos em Java**, com foco na prática de **Listas (`List`)**, **laço `for-each`**, **Programação Orientada a Objetos (POO)** e **manipulação de dados**.

O sistema simula um cadastro simples de funcionários, permitindo registrar informações, aplicar aumento salarial e exibir os dados finais de forma organizada.

---

## 🚀 Funcionalidades

* Cadastro de funcionários com:

  * ID
  * Nome
  * Salário
* Armazenamento dos dados em uma **lista de objetos**
* Busca de funcionário pelo **ID**
* Aplicação de **aumento salarial por porcentagem**
* Listagem final dos funcionários utilizando **`for-each`**

---

## 🧠 Conceitos Praticados

* Programação Orientada a Objetos (POO)
* Classes e Objetos
* Encapsulamento
* Listas (`List` e `ArrayList`)
* Laço `for-each`

* Entrada de dados com `Scanner`

---

---

## 📌 Exemplo de Funcionamento

1. O usuário informa quantos funcionários deseja cadastrar
2. Insere os dados de cada funcionário (ID, nome e salário)
3. Escolhe um funcionário pelo ID para receber aumento
4. Informa a porcentagem de aumento
5. O sistema exibe a lista final com os salários atualizados
